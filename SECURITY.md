# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately through GitHub's **Report a vulnerability** feature in the repository's Security tab. Do not disclose vulnerabilities in public issues or pull requests.

The maintainers will acknowledge reports and coordinate a fix and disclosure with the reporter. Please include the affected version or commit, steps to reproduce, and any potential impact.

## Supported versions

Until releases are published, the latest commit on the default branch is the only version considered for security fixes.
